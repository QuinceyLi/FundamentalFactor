# 市值代理中性化验收记录（2026-10-27）

本次增加可选的行情代理市值控制，使用既有因子值做横截面中性化及分组回测，不训练收益预测模型，不调用持仓优化器。完整用法见 [README](../README.md#行情代理市值与市值中性化)。

## 数据与计算

代理公式为 `close * volume * 100 / (turnover / 100)`，结果单位为元：未复权收盘价 × 成交量（手）× 100 股/手 ÷ 换手率（百分数换成比例）。它依赖换手率分母的口径，始终标记为代理，不写入实际市值列 `float_mcap`。

- 原始价量：`outputs/gfoptim_inputs/raw_quotes.parquet`，由既有数据适配器合并原始行情。清单记录新旧源重叠 3,121,636 条的开盘、收盘、成交量无冲突。
- 换手率：`/data/mongo/quotefac_repaired.feather` 的 `turnover`；收益继续使用该文件的复权行情字段。
- 独立抽样对照：已有东方财富原始缓存中 `000001.SZ` 在 2025-05-20—2025-06-20 的 23 个交易日。收盘价全部一致，成交量最大差 0.5 手，换手率最大差 0.0049 个百分点，符合该接口舍入精度。成交额除以股数均落于当日高低价之间。这是抽样单位验证，并非全历史数据认证。
- 本次不修改源文件。审计记录路径、字段、单位、覆盖及版本指纹，详细本地证据在 `outputs/market_cap_proxy_validation_20261027/source_review.json`。

在每个调仓截点分别向历史取两个来源的最新记录，只在日期相等时计算；该算法等价于同日外连接后取最新记录。未来记录、不同日期的价量与换手率、最新记录的非正或非有限值均不能形成有效代理，不越过无效更新回取更旧有效值。

`size` 以截距及对数市值做当期等权 OLS，取残差作为信号；数值计算先缩放对数市值，保持相同回归空间。`industry_size` 同时加入行业，`full` 根据 `include_float_mcap` 决定是否加入市值。`sample_policy=independent` 下各版本独立取样。代理输入、来源日期、结果和无效原因保存在控制、信号及持仓明细中；覆盖率按版本披露。

## 本地实际数据验收

用 `factor_test_size_proxy_weekly.json` / `factor_test_size_proxy_monthly.json` 的副本将区间固定为 2025-01-01—2025-07-07，分别比较 `raw` 与 `size`，关闭去极值和标准化。冻结副本和报告位于 `outputs/market_cap_proxy_validation_20261027/`；原示例配置保留完整可用历史区间。

逐项验收结果：

- 所有有效代理与原始输入重新计算的公式逐值相同，来源日期相等且不晚于截点。
- 对比此前相同区间的直接因子测试，原始因子的值、样本、排名、分组及 IC 完全一致。组合及绩效指标最大绝对差约 `1.07e-14`，属于浮点精度；验收容差为 `1e-12`。
- 市值中性残差与中心化对数市值的归一化内积绝对值最大为 `2.33e-16`，符合正交要求。
- 两种频率的两因子均生成独立 HTML 报告。验收摘要在 `validation_summary.json`，逐项核对脚本在 `validate_runs.py`（均位于上述本地输出目录）。

这段样本用于工程验收；因子表现应在需要的研究区间另行评价。新示例保持原始样本独立，版本间表现差异可能同时包含中性化效果及样本变化。
