# 统一因子研究报告

`python -m fundamental_factor report --run-dir <运行目录>` 与 `run`、`audit`、`build-panel` 的报告入口均使用 `fundamental_factor/report.py`，只生成一套研究界面。原报告的 HTML 拼接器、旧图表脚本与逐因子渲染器已移除。运行目录的 `report.html` 可离线打开；原 `factors/<因子>/report.html` 仅跳转到统一界面。

## 输入与输出

报告读取冻结配置、审计、面板清单和已完成结果，核验四者的配置指纹。失败记录、未完成结果或指纹不一致时不展示残留绩效。报告生成不重算信号、改动分组或覆盖原始数据。

- `portfolio_weekly.csv`、`ic_weekly.csv`、绩效与年度表：沿用现有回测数值，兼容周度和月度。
- `holdings.parquet`：读取 Q1、Q10、ALL 的冻结目标权重，剔除退出记录。
- `controls.parquet`：行业名称及历史实际流通市值；行业按运行目录 `industry_mapping.csv` 中的分类体系解释，AIQ 35 类不与旧 `class_1…35` 混用。
- 风格分析：优先使用冻结控制字段，必要时按配置风险源补充截点前可知的风险暴露；不据此重新筛选持仓。
- `report_data.json`：可独立复核的报告数据。HTML 内嵌同一数据、脚本、字体及样式，无 CDN；大型报告内嵌压缩数据，由浏览器离线解压。

独立样本模式中 ALL 为当前信号版本可用样本，不能称为跨版本共同样本。研究股票池参照独立于因子和控制字段覆盖。持仓分析使用目标权重；收益统计使用回测原有有效标签口径，二者不混用。

## 行情分类

以中证全指收盘价计算 `MA20 / MA120 - 1`，大于 3% 为上涨、小于 −3% 为下跌，其余为震荡过渡。对每个入场日仅使用此前最近交易日收盘状态。回测收益基准仍是研究股票池等权。

随包提供 2012-01-04 至 2026-10-26 的公开指数快照；来源与哈希见 `fundamental_factor/report_data/csi_all_share.json`。不足120个交易日不分类。没有可用来源，或入场已超过指数历史末端且距最后记录超过7个自然日时显示未知。历史覆盖范围内的长假使用节前最近收盘，不误判为数据过期；不向未来取值。可通过冻结配置的 `report.market_index` 指向同格式 `date,close` CSV；超出快照覆盖的回测需提供更新数据。

行情条件表使用对应期间的均值、胜率、波动和换手；净值、IC 时序与年度分析保持完整时间轴，不把离散行情拼接成连续回测。

## 持仓结构

行业按每期目标权重聚合，缺失保留未知类别，现金单列。总览“权重最大行业”在全部单一行业中排序，不将“其他”合计当作一个行业。

风格按当期可投资股票池的截面均值和总体标准差标准化；持仓加权平均伴随逐项有效目标权重覆盖率。AIQ 模式沿用字段矩阵的历史向前填充规则，不读取未来观测；填充后仍缺失的值不补0，标准差为0时不可计算。持仓暴露是描述统计，不是收益归因。

相对风格暴露先按同一期配对持仓与参照，再计算跨期均值。两侧有效权重较小值作为覆盖代理，并非逐股交集权重。无法读取持仓的期间剔除并披露；实际空组现金期保留。

市值分档按当期股票池正的实际流通市值五分位，保留并列；组合加权中位市值按元计算、前端按亿元展示。规模风格 SIZE 与实际市值分别展示。

## 界面

研究总览、IC分析、分组回测、年度表现、行情表现、持仓结构、中性化对照、基准与覆盖、统计口径九个栏目。支持因子、信号、时间和行情筛选，表格导出、全分组图例与打印。未配置的信号版本不生成，缺失数据保留空态。
