# AIQ 本地数据接入与因子测试

本次接入以 `/data/AIQ/` 为本地参考数据首选，源文件只读，转换和隔离文件保存在 `outputs/aiq_inputs_20261028/`。收益价格继续使用 `/data/mongo/quotefac_repaired.feather`；AIQ 的已知异常复权列没有被读取或复制为收益价格。已有 ROIC、公募持仓变化成品因子的口径也继续保留。

新推荐配置显式设置 `missing_values.method=aiq_matrix`，对上述来源的数值字段采用AIQ矩阵补缺规则；它改变研究输入的缺失处理，不改原始因子公式和文件。省略该配置或选择 `preserve`，仍保留此前显式缺失更新。新结果写入带 `_aiq_matrix_20261028` 的输出目录，本文末尾旧运行数值明确标为历史口径。详细字段规则见[缺失值说明](data_missing_policy.md)。

## 数据选择

| 用途 | 本次来源 | 处理与回补 |
|---|---|---|
| ROIC / 公募持仓变化 | Mongo 明细成品因子 | AIQ 未提供相同口径的这两个成品；不把原始财务/持仓直接替代成品 |
| 收益价格 | Mongo 已修复 `quotefac_repaired.feather` | 独立保护指纹；不用 AIQ 复权行情替换 |
| 行业 | AIQ `zx_sector1/2/3.csv` | 适配层保留真实区间与空事件；aiq_matrix另按mark_industry前填测试类别，原始未知和填充标记分别保留 |
| ST | AIQ `st.csv` + `previous_name.xlsx` | 当时有效的事件/简称核验；未知用已有官方 SZSE 历史补充，直接冲突以官方事件为准 |
| 流通市值 | AIQ `market_feature.feather` | `circulated_market_value × 10000` 转元；aiq_matrix只填原始NaN，0/负/inf仍无效，保留原记录与提供值日期 |
| 证券生命周期 | AIQ 证券主表 + `delist_stock.csv` | 明确退市日期优先；现有交易所主表补充 AIQ 缺失证券；差异另表记录 |
| 日历 | AIQ `tradeday.csv` | AIQ 覆盖内采用该日历；此前日历由已有公开源补充，用于上市年龄 |
| 停牌与开盘涨跌停 | AIQ 原始量价计算代理 | 新矩阵阶段在生命周期内重建日网格，volume按规则补0、close/last前填、open保持缺失，再计算代理并保留填充标记 |
| Barra | 本次四个版本不启用 | 不作为原始、行业、市值或行业市值版本的数据门槛 |

使用的因子仍是 `ROIC_new` 和 `fundnum_promotion`。本轮没有加入模型训练、持仓优化器或新的因子公式。

源规则有两个需按原义解释的地方：类24虽然叫“化学制药”，实际上接纳整个中信一级“医药”；类35包含综合、综合金融、非银/地产的部分剩余分类及五个条件股票例外。旧 `industryclass.xlsx` 的25/26类标签已过时，不参与命名。标准中信一级30类仍可通过 `classification=citic_l1` 显式选择，旧配置没有被混称为35类。

实际源核验：三张历史表各9,077行；隔离特殊代码 `T00018.SH` 的三级共3条记录。导出5,804只股票、9,516个状态事件，其中9,076个分类事件、440个空值终止/间隔事件。按代码与起始日连接的9,076个可比样本分类一致；这是本地同源规则核验，不是独立供应商认证。

原始适配层的日期规则（两种缺失配置共用）：

- `start` 是原生效日，不提前到前一交易日。
- `end` 按包含当天处理，`end+1` 明确写入空值；源大量连续区间符合“旧end+1=新start”。配置入口的转换函数也支持显式选择不包含end。
- 二三级变更也产生事件；缺少必要子级、跨级冲突或重叠区间保持未知。不能把缺一级归为“综合”。
- 每周/月截点只向后匹配，绝不向过去倒填未来分类。规则的历史版本、供应商首次发布与事后修订档案仍缺，报告明确披露。

研究输入层再按缺失配置选择：`preserve`保留上述空事件；`aiq_matrix`按AIQ `mark_industry()` 的ffill方式跨过空事件，延续此前35类类别。此时保留 `industry_original`、原始层级/状态、是否填充和提供分类值日期。填后的行业可用于这项研究，但不能据此声称空档/冲突已有真实有效分类，也不能把原始覆盖率与填后可用率混为一谈。

## ST：可核实状态、代理与未知分开

AIQ `st.csv` 包含未保留 `S_TYPE_ST` 类型的事件，混有暂停/退市等情况；`announce_date` 也不能一律解释为首次ST公告。适配层因此同时检查当时简称和事件。

1. 事件与ST简称一致时记录双证据ST；单独有效简称也保留代理来源。普通简称和未分类事件冲突、退/PT简称、重叠冲突等保留未知。
2. 简称历史最新生效日仅 **2022-11-25**。其开口区间在该覆盖代理上限翌日失效，不能延续到2026。
3. ST事件最新生效日为 **2026-10-23**；这不能让旧简称变新，也不能证明全市场每天都有完整ST状态。
4. 名称区间结束日包含当天；ST取消日是取消生效日，不包含在ST区间内。保留源自然日，不把周末公告或名称提前至前一交易日。
5. 两个来源的事件日取并集后逐源向后匹配，未知过期事件不会被前填抹掉。AIQ未知可用官方SZSE已验证历史补充，直接冲突按官方事件处理并单列 `st_source_disagreements.csv`。

AIQ适配本身输出19,867条边界，其中12,657条已知状态、2,636条双证据ST。**这些是事件边界数，不是股票日覆盖率。** 最终股周/月覆盖率从实际股票池重新计算，写入每次报告。原始因子研究仍按经典规则纳入未知ST并披露，已知ST剔除；未新增“缺完整ST即停测”的门槛。

## 直接流通市值与异常

源字段 `circulated_market_value` 对应 Wind `S_DQ_MV`，单位万元；接入层乘10000后统一为元。中性化使用 `log(float_mcap)`。Barra SIZE和加工后的tmv不作为该原值。

核验对照包括：

- `float_shares(万股) × 原始close × 10000`。股本最早可用日取事件日期、报告/公告、除权、上市/变更等提供日期的最晚日，同键冲突不会任取一条。
- `原始close × volume(手) × 100 / (turnover(%) / 100)`。量价与换手率必须同一股票日，不使用入场当日完整成交量。

此前基础适配核验中，原始25,024,665行先排除8,400,210条非交易日记录及191条非A股代码记录，保留16,624,264个股票日。93,305条非有限/非正市值保留键及隔离原因，同时保留原值 `raw_mcap_wan`。这些是适配层统计，不是新矩阵规则下实际调仓样本的填充统计。

股本公式比较12,739,089行，98.202823%在2%误差内；原有代理比较12,425,751行，99.997409%在2%内。2%是诊断阈值，普通分歧仅披露；只有两个公式相互一致且共同显示百倍级差异才隔离有效正值。本次没有这种双公式佐证的极端异常。普通分歧仍需后续逐股检查，也不宣称两个本地交付源相互独立。

市值源覆盖2005-12-30—2026-10-22。信号匹配严格限制在截点之前，未来市值不能进入更早截点。`preserve`保留最新缺失/异常；`aiq_matrix`先恢复 `raw_mcap_wan` 中的原始数值，再应用AIQ默认ffill和单位换算。仅原始NaN可用此前值填充；0、负数、无穷值不能借隔离NaN绕过，最终有效市值仍须有限且为正。记录原始缺失、填充和提供值日期；补缺后仍缺失只影响需要市值的版本。

## 停牌、涨跌停、收益和缺失

停牌沿用GF规则：未复权成交量为零或收盘价为零；非法量价为未知。开盘涨跌停继续使用已有板块、ST、除权参考价规则，是限制诊断代理。AIQ稀疏停牌事件未提供完整停复牌时段，发生在有成交量的日期也可能是部分停牌，所以只交叉核查，不直接把这些股票日全标为停牌。旧zdt缓存只到2022年，且收盘涨跌停和开盘不可交易语义不同，不静默替换开盘代理。

代理使用全日数据，不能认证开盘前已知或完全可成交。AIQ矩阵规则适用于数值输入，不把未知布尔状态一律填成正常；ST的单表/事件入口没有被通用矩阵ffill替代。研究收益继续使用已修复复权开盘价；`aiq_matrix`对 `acc_open` 延续其自身此前值，对raw `open`则保持缺失，不再以已知停牌为由把开盘换成前收盘；`preserve`保留此前估值约定。端点补缺分别标记。证券生命周期仍有效，退市后的旧价不能被当作实际观察退出价；实际退出价值无法确定时保留缺失。完整公司行动/实际退市结算不是统一因子统计门槛。

各版本独立取样：raw只要求所选缺失策略处理后的有效成品因子；industry要求对应行业；size要求有效直接市值；industry_size要求两者。行业、市值或Barra缺失不删除raw股票。先冻结信号/分组，再配对未来标签；收益缺失采用已声明的有效收益样本统计，保留冻结目标权重、统计权重及缺失披露。行情日收益字段的补0规则不套到所有未来标签上。

## 新默认补缺与可选预处理

```json
{
  "missing_values": {"method": "aiq_matrix"},
  "preprocess": {"winsorize": false, "standardize": false},
  "smoothing": {"method": "none"}
}
```

普通因子、close、复权价格及市值字段默认ffill；volume/amount/return/vwap在首个非空值后缺失补0；raw open/high/low及turnover等保持缺失；特定日内vwap/twap字段用last。按源列名确定策略，首个历史非空值之前不补、绝不从未来填值。原始记录与提供值的日期、原始缺失与填充结果分别披露。

EMA、去极值、标准化和中性化独立于这一补缺开关。全部关闭时测试补缺后的值；若要保留原快照的显式缺失，则选 `missing_values.method=preserve`。EMA在补缺之后递推，成功前填不会仅因原NaN重置；仍缺失和股票池断档继续重置。

本轮对齐的是AIQ `FP.mat()` 字段矩阵规则，**不叠加 `getfactor()` 的横截面回归补缺**。后者使用日期×中信一级行业和原始总市值拟合缺失因子，是另一套输入处理，并非本项目的行业/流通市值中性化。保留这一边界也避免让raw因子测试新增行业/总市值依赖。

## 运行与追溯

```bash
python3 scripts/prepare_aiq_inputs.py
python3 scripts/prepare_aiq_matrix_inputs.py
python3 -m fundamental_factor audit --config configs/factor_test_aiq_weekly.json
OPENBLAS_NUM_THREADS=1 python3 -m fundamental_factor run --config configs/factor_test_aiq_weekly.json
OPENBLAS_NUM_THREADS=1 python3 -m fundamental_factor run --config configs/factor_test_aiq_monthly.json
```

`--reuse-adapters` 仅供同一次核验过程复用已验证的行业/ST/市值产物；完整重新准备时使用默认命令。准备输出必须在AIQ/Mongo源目录之外。缓存冻结来源和适配说明指纹，变更后必须使用新结果目录。

`factor_test_aiq_weekly_ema.json` / `factor_test_aiq_monthly_ema.json` 提供可选EMA；主配置保持EMA、去极值和标准化关闭，但显式采用AIQ矩阵补缺。直接输入的raw预设仍可单独使用，其冻结的 `missing_values` 设置决定是否保留原始缺失。旧配置省略该项仍是preserve，不被新默认悄悄改写。

每次输出新增 `data_usage.csv`、`data_quality_summary.csv`、`industry_distribution.csv`，并嵌入HTML报告。主面板、控制面板和信号保留来源日期、ST证据、行业层级/类别、市值异常原因。接入总manifest记录原始文件、保护行情指纹、优先级和剩余改进项。
