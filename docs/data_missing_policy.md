# AIQ 缺失值规则与回测口径

更新日期：2026-10-28。新推荐配置显式采用 `missing_values.method=aiq_matrix`，按 AIQ `Tools/datahub.py` 的字段规则处理缺失。源文件只读，补缺发生在研究输入层，不回写 `/data/AIQ/`、`/data/mongo/` 或已修复行情。

## 配置与兼容

```json
{"missing_values": {"method": "aiq_matrix"}}
```

`method=preserve` 保留此前规则：向后匹配最近记录，显式缺失新记录终止旧值，不跨过它寻找旧非空值。**省略整个配置项也采用 preserve**，用于兼容已有冻结配置；新推荐配置则明确声明 `aiq_matrix`。两种结果使用不同输出目录，新运行写入名称带 `_aiq_matrix_20261028` 的目录，不覆盖此前报告。

切换面板补缺开关不会重建已经生成的交易状态。完整复现旧口径必须同时使用旧冻结配置和原状态输入；新 `outputs/aiq_matrix_inputs_20261028/trade_status.parquet` 已按补缺后的量价生成，不能只把开关改为preserve就称为恢复了旧股票池。

补缺与因子计算、去极值、标准化、EMA、中性化是不同步骤。仍直接接收已经计算好的外部因子，不重算财务或持仓公式。关闭 EMA、去极值、标准化和中性化，表示直接测试**补缺策略处理后的输入**；同时使用 `preserve`，才保留原快照的显式缺失语义。

## 按源字段名选择 AIQ 规则

对应源码：`/data/AIQ/Tools/datahub.py` 的 `FILL_RULES`、`_apply_fill()`、`DataHub.mat()`。规则按实际源字段名选择，不因框架把列重命名为 `value` 或 `open_level` 而改变。

| 源字段 | AIQ 规则 | 新版本含义 |
|---|---|---|
| `volume, amount, return, vwap` | `zero` | 每只股票、每个字段的首个非空值之前仍缺失，此后缺失补0；已有非空值不改写 |
| `turnover, free_turnover, open, high, low, zdtmark, fy1, CAGR` | `keep` | 保留对应交易日的缺失，不从其它日期补值 |
| `vwap_30toe`—`vwap_210toe`、同范围每30分钟的 `twap_*toe` | `last` | 缺失时用同股票同日的 `last`；无法提供该填充源时按AIQ规则退化为前填；主回测没有使用这些日内字段 |
| 其它字段，如 `close, acc_open, acc_close, total_market_value, circulated_market_value, ROIC_new, fundnum_promotion` | `ffill` | 只沿每只股票历史向前延续，包括越过显式NaN；首个非空值之前不补 |

`open` 与 `acc_open` 的规则不同：前者保持缺失，后者走默认前填。`acc_open` 缺失时延续的是此前 `acc_open` 本身，不能替换成前收盘价并仍称为同一规则。`return` 是行情表中的日收益字段，不是本项目新计算的周/月未来收益标签；日收益列的补0规则不等于所有未知组合收益都补0。

补缺层识别的是空值，不把0、负值或无穷值视为可越过的NaN。因子及控制变量还要通过其经济含义对应的有效性检查；市值、价格的非正值不能作为有效规模或价格使用。原始值、补缺前缺失、实际填充标记和提供值的历史日期分别保留，不能把延续值称为当天新观察值。

AIQ默认前填没有最大时长。本轮3条周度市值前填分别使用约2、10、14个月前的供值；它们按所选规则可用于计算，但不代表当期新观察市值，供值日保留在 `float_mcap_value_source_date`。

同一例子在两个配置下的结果：

```text
周四 ROIC 记录=100，周五明确记录=NaN，周一调仓：
preserve   → 因子缺失。
aiq_matrix → 因子=100，标记已前填，提供值的日期为周四。

若字段改为 turnover，AIQ规则是keep，周五仍缺失。
若周五市值原始值为0，不能通过先转NaN再前填恢复周四的有效市值。
```

## 各数据层如何应用

### 因子与中性化控制

因子按源列名补缺后，再在调仓截点取值。前填只使用截点已可得的值，不能后填或使用调仓日收盘信息。有限的真实零值和负值保留。补缺后仍无有效值的股票不参与该因子的当期分组。

独立样本规则继续成立：`raw` 只需要有效因子；`industry` 需要行业；`size` 需要市值；`industry_size` 需要两者；`full` 再需要选定的风险暴露。控制缺失或某个中性化版本失败不删除 `raw` 股票。共同样本模式仍按所选控制交集取样。

EMA 位于输入补缺之后。前填成功的因子已是该层有效输入，不会仅因原快照为NaN而触发EMA重置；补缺后仍缺失、或股票池断档，仍按EMA模块规则重置。覆盖和填充披露保留两种区别。

### 行业：保留原状态，单列前填后的测试类别

行业适配文件仍记录生效、终止和冲突，原始层级、中文标签与状态不改写。`preserve` 下，`end+1` 的空事件阻止旧行业延续。

`aiq_matrix` 下，测试类别按 AIQ `mark_industry()` 的前填方式延续，允许跨过空事件。输出保留 `industry_original`、原始缺失/状态、是否填充及提供分类值的历史日期。**填充后的35类可用于本次测试，不表示已经取得该空档内真实有效的新分类。** 缺一级且从未有过有效分类的证券仍未知，不凭空归到“综合”。35类规则与中文名称本身不变，也不被误称为标准中信一级30类。

### 市值：原始缺失与非法数值分开

直接流通市值适配文件保留原值 `raw_mcap_wan`。`aiq_matrix` 在矩阵补缺前恢复该原始量纲值，再按万元转元，防止把此前隔离为NaN的0、负数或无穷值误当作普通空值并用旧有效值替代。

原始NaN按默认前填；原始0、负值、无穷值保留到有效性检查，最终仍不作为有效市值。来源日期、提供值日期、填充标记和原异常原因分别可追溯。行情代理使用各输入的原字段策略后计算，且仍要求价格、成交量、换手率的交易日与单位一致，不能把旧换手率与新价格拼成已观察的真实市值。

### ST、停牌与交易域

AIQ 的 `FP.ST` 是单表入口；`st_mark()` 根据实施/取消事件累计，并非对 `is_st` 通用补0或前填。当前历史ST继续使用适配后的事件语义，保留来源过期、冲突和覆盖未知。未知允许进入研究股票池不等于认证为非ST；已知ST仍剔除。不能用矩阵补缺延长已过期的ST证据。

停牌和涨跌停仍需说明所用代理、数据层和信息时点。数值字段补缺和已有布尔状态不是同一对象；不能把未知布尔状态直接填成“正常”。全日成交量形成的停牌代理不被称为开盘前已知的交易事实。

证券上市/退市有效期继续限制研究和估值范围。矩阵前填不能把退市后的旧价格变成已观察退出价格，不能虚构退出现金。

### 价格、收益与统计

价格按 `price_contract` 指定源列的 AIQ 规则处理，端点填充需要单列。已知停牌另按声明的估值规则处理；这与 `acc_open` 自身的前填是两个可区分步骤。生命周期结束后没有观察退出价格或可靠结算的标签仍缺失，前填价格不能触发“经典模式已有观察退出价格”的例外。

未来收益、IC和组合统计不一律补0。先冻结信号与分组，再计算持有期标签；无法恢复的收益保持NA。`available_case` 在冻结组内按有效标签对应目标权重归一计算统计收益，仍保留缺失目标权重；不能因此反向改变排名。真实空组按 `empty_groups=cash` 记现金收益0，非空组全部标签缺失或整期无信号仍为NA。

换手、夏普和累计净值继续使用各自有效性规则；没有恢复个股收益时，不能靠组合统计收益反推已知的持仓漂移。

## 为什么没有额外调用 getfactor() 的回归补缺

AIQ 的两条入口有不同的默认行为：

```text
FP.mat()/字段属性：长表 → 交易日×股票矩阵 → 按FILL_RULES补缺

FACPROCESS.getfactor()：宽CSV → _reindex（只重排）→ 可选fill0（默认关闭）
  → 股票池遮罩 → _fillna_regress（默认开启）→ 可选winsor → 可选normal
```

`_fillna_regress()` 按“日期×中信一级行业”回归缺失因子，解释变量为**原始总市值与截距**；WLS未设置特别权重，实质为普通最小二乘。它不是35类行业/流通市值中性化，也不是矩阵时序前填。`getfactor()` 不先对因子默认执行时序ffill，`_reindex()` 本身也不填值。

本轮统一的是用户所指的 **AIQ矩阵字段缺失规则**，没有再叠加另一入口的横截面回归补缺，也没有擅自开启其默认缩尾和市值加权标准化。这样仍能保持原始因子不依赖行业/总市值。若以后明确选择 `getfactor()` 回归补缺，应作为单独规格记录输入、样本与失败规则，不能宣称它与本轮矩阵规则相同。
